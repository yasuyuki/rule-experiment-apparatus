# 実行の単位（所属基準）

実験非依存の所属基準の正本。サイクル宣言は本ファイルの sha256 を
`executionUnitHash` として pin する。セッションの一覧は宣言に書かない。
列挙と所属の確定は `judge` 時に行う。

判定形式（JSONL のどの欄を見るか、アーム束縛の導き方）は subject 記述子が持つ。
この文書は「参加とは何か」「所属とは何か」だけを定める。

## 1. 参加セッション

参加セッションは、subject が実際に何かを実行したセッションである。起動しただけの
セッションは含まない。

参加か否かの判定形式は subject 記述子の `transcripts.participation` が持つ。
装置は記述子が示す形式で件数を数え、1 以上なら参加とする。marker の数え方は
判定器の仕事であり、装置は持たない。

## 2. 所属

あるセッションがそのアームの実行に属するとは、subject 記述子が示すアーム束縛で
そのアームに束縛されることである。

- `project-slug`（claude-code）: transcript の project ディレクトリ名が、アーム
  絶対パスの `/` を `-` へ置換したものと一致する
- `cursor-project-slug`（cursor-agent）: transcript の project ディレクトリ名が、
  アーム絶対パスの先頭 `/` を落としてから `/` を `-` へ置換したものと一致する
- `session-meta-cwd`（codex）: transcript 先頭行 `session_meta` の `cwd` が、
  そのアームの絶対パスと一致する
- 記述子が `null`（未確認）の束縛: 確定できない

## 3. 確定できない場合

装置は選ばない。次のいずれかが 1 件でもあれば、そのサイクルを比較から外す。
食い違いは 1 件で止めず全件集めて出力する。

- 所属を確定できないセッション
- そのアームの config root で発見したのに、そのアームへ束縛されないセッション
  （隔離の取り違え・汚染）
- 参加セッションが 0 件（証拠が無い）

件数の上限は設けない。複数セッション・複数 subject は正常系である。

## 4. span

所属する参加セッション集合の span の和である。各セッションの最初の timestamp から
最後の timestamp までを区間とし、集合全体の最早から最遅までを和とする。
境界は閉じる（最早・最遅そのものの時刻は内包される）。

timestamp を持つ行が 1 つも無い参加セッションがある場合は span を作れないので
拒否する。

注入 commit 以降のアームの全 commit の author time は、この和に内包されなければ
ならない。外れた commit は観測されていない主体の痕跡であり、拒否する。

## 5. この規則が答えない問い

- どのセッションに marker が要るか（実験ごとの計測仕様の仕事）
- セッションが何件あるべきか（数は基準ではない）
- 複数の参加セッションを判定器へどう渡すか（`judge.py` の引数形は実験の仕事。
  現行の判定器は transcript 1 件を取る）
